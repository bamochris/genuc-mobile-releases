# GENUC Mobile — APK

Application mobile GENUC (plateforme universitaire RDC).

## Télécharger

Dernière version : voir l'onglet **Releases** →
https://github.com/bamochris/genuc-mobile-releases/releases/latest

Fichier : GENUC-Mobile-v1.0.0.apk (Android, ~82 Mo)

## Installer

1. Télécharger l'APK sur le téléphone Android.
2. Ouvrir le fichier ; autoriser « Installer des applications inconnues » si demandé.
3. Lancer GENUC Mobile et se connecter avec ses identifiants.

Serveur : https://genuc.up.railway.app
